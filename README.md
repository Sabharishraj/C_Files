# C-Files

A simple collection of **C programming practice programs** that I wrote while learning C from scratch.

This repository is meant to:

* Help **beginners** understand C basics
* Act as a **reference** for simple programs
* Track my **learning progress** as a 1st-year student

---

##  About

* Language: **C** (few `.cpp` files included for learning)
* Level: **Basic to Intermediate**
* Focus: Logic building and core fundamentals

All programs are kept **short, clear, and beginner-friendly**.

---

##  Topics Covered

### Basics

* `hello.c` – Hello World program
* `input.c`, `input_no.c` – Basic input handling
* `simple_for.c` – for-loop example
* `function.c` – Functions in C

### Numbers & Logic

* `factorial.c` – Factorial of a number
* `prime_numbers.c` – Prime number check
* `palindrome.c` – Palindrome check
* `power.c`, `power.cpp` – Power of a number
* `square.c`, `sq` – Square of a number
* `sumrc.c`, `sum` – Sum calculation (recursive/basic)
* `roundoff.c` – Rounding off values
* `vote.c` – Eligibility check using conditionals

### Arrays

* `arr` – Basic array operations
* `element_reverse.c` – Reverse array elements
* `freq.c`, `freq` – Frequency of elements
* `multidimensional_array.c` – 2D arrays

### Searching & Sorting

* `linear_search.c` – Linear search
* `binary_sort.c` – Binary-based sorting
* `bubble_sort.c` – Bubble sort

### Matrices

* `transpose.c`, `transpose` – Matrix transpose
* `det_2.c` – Determinant of 2×2 matrix
* `det_3.c` – Determinant of 3×3 matrix

### Macros & Pointers

* `square_macros.c` – Macros example
* `checker_macros.c` – Macros with conditions
* `getch.c` – Character input handling

### Data Structures (Intro)

* `linked_list-1.c`,`linked_list2.c` – Singly linked list basics
* `node.c`, `node` – Node structure understanding
* `stack_array.c`,`queue file.c` - Implementation of stacks and queue using array
